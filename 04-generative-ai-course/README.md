# Generative AI Course Projects

Selected coursework from the TAICA course **Generative AI: Text and Image Synthesis Principles and Practice** (生成式 AI：文字與圖像生成的原理與實務), taught by Tsai Yen-Lung (蔡炎龍).

This section includes my submitted homework and final-project work. Instructor lecture PDFs, third-party reference material, and unmodified official / TA demonstration notebooks are not included.

## Homework

[`homework/README.md`](homework/README.md) provides a compact HW1–HW14 index together with setup, API-secret, and external-file requirements. Not every homework has an `.ipynb`; PDF-only submissions are kept as PDF artifacts.

HW7 RAG (2), for example, now takes the FAISS archive generated by RAG (1) instead of depending on the expired shared Drive archive.

## Final Project — AI Tutor

[`ai-tutor-final-project/`](ai-tutor-final-project/) documents **全能 AI 家教**, an interactive tutor using the Groq API, LangChain, FAISS, Google Colab, and Gradio.

The system supports learner question answering, follow-up quiz/feedback interaction, PDF-based learning material, and a web-search fallback.

The submitted presentation/demo used `llama-3.3-70b-versatile`; the current repository notebook uses `openai/gpt-oss-120b` because the original model is not available to the current Groq project/API key. See the project README for the reproduction note.

The working YouTube demo and submitted presentation are linked from the project README. The original Colab share URL has expired and is therefore omitted.
